# AMM 与订单簿

为什么不使用链上订单簿？AMM 解决了什么问题？

```
Gas - AMM 执行交易的 gas 成本比订单簿更低
流动性 - 比链上订单簿的流动性更好
```

### 什么是流动性

```
流动性 - 资产在不影响其市场价格的情况下
         转换为现金的难易程度（Investopedia.com）
```

### 链上订单簿

##### 操作

- 买方
  - 存入资金
  - 出价（Bid）- 提交买单
  - 更新订单
  - 取消订单
- 卖方
  - 存入代币
  - 要价（Ask）- 提交卖单
  - 更新订单
  - 取消订单
- 订单簿
  - 按价格对订单排序
  - 撮合并执行订单

##### 缺点

- gas 成本高昂 🔥
- 流动性低 💧
- 交易量低 🔈

### AMM

##### 操作

- 流动性提供者
  - 存入代币
- 交易者
  - 与 AMM 兑换代币
- AMM
  - 执行交易
  - 通过算法计算兑换汇率
  - 将兑换手续费分给流动性提供者

##### 优点

- 节省 gas ✅
- 流动性高 💧💧💧
- 交易量高 🔊

##### 缺点

- 流动性提供者通常处于亏损状态 💸
