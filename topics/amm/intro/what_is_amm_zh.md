### 什么是 AMM？

```
AMM - 自动做市商（automated market maker）

一种去中心化交易所，允许用户在没有订单簿的情况下
买卖代币。
```

### 价格是如何确定的？

```
价格由算法决定，通常是一个数学方程。
```

### 用户与代币流向

```
- 交易者（Traders）
  - 存入一种代币以换取另一种代币
  - Token in（交易者发送给 AMM 的代币）
  - Token out（交易者从 AMM 收到的代币）

- 流动性提供者（Liquidity providers）
  - 同时是两种代币的卖方
  - 通常向 AMM 存入两种代币
  - 赚取兑换手续费
  - 取出代币
    - 取出数量不一定与存入数量相同
    - 取出数量由 AMM 中的代币数量决定
```
